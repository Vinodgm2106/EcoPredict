# 🌍 EcoPredict – Environmental ML Platform

EcoPredict is an advanced Machine Learning powered environmental risk prediction platform built using Python, Streamlit, Scikit-learn, and Plotly.

The project demonstrates end-to-end ML workflow including:
- Data preprocessing
- Missing value handling
- Probabilistic prediction
- Uncertainty estimation
- Explainable AI
- Geo-spatial visualization
- Interactive dashboard analytics

```bash
EcoPredict/
│
├── eco.py
├── README.md
└── requirements.txt



``# ▶️ How to Run the Project

## 1. the Repository

```bash
cd EcoPredict-Environmental-ML
```


## 2. Install Required Libraries

```bash
pip install -r requirements.txt
```

## 3. Run the Streamlit Application

```bash
python -m streamlit run eco.py
```


## 4. Open in Browser

After running the command, Streamlit will automatically open the application in your browser.

Default URL:

```text
http://localhost:8501
```

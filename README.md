# 🌍 EcoPredict – Environmental ML Platform

EcoPredict is an advanced Machine Learning powered environmental risk prediction platform built using Python, Streamlit, Scikit-learn, and Plotly.

The project demonstrates end-to-end ML workflow including:
- Data preprocessing
- Missing value handling
- Probabilistic prediction
- Uncertainty estimation
- Explainable AI
- Geo-spatial visualization
- Interactive dashboard analytics

---

# 🚀 Features

✅ Advanced Data Cleaning & Validation  
✅ Environmental Risk Prediction using Machine Learning  
✅ Prediction Uncertainty Visualization  
✅ Explainable AI using Permutation Importance  
✅ Interactive Geo-Spatial Risk Mapping  
✅ Confusion Matrix & Model Diagnostics  
✅ Streamlit Interactive Dashboard
